# 医院管理系统 (Hospital Management System)

这是一个基于 .NET 8.0 的C#控制台应用程序，用于模拟一个简单的医院管理系统。

系统支持三种不同的用户角色：管理员 (Administrator)、医生 (Doctor) 和病人 (Patient)。它使用文本文件（.txt）作为数据存储，实现了基本的登录、数据管理和特定角色的功能。

## 主要功能 (Features)

### 通用 (General)

* **用户认证：** 用户通过唯一的ID和密码登录系统。系统会验证ID和密码是否与管理员、医生或病人的记录匹配。
* **数据持久化：** 系统数据（医生、病人、管理员、预约）通过 `FileManager` 在启动时从文本文件加载，并在更改后保存回文件。
* **角色路由：** 成功登录后，系统会根据用户类型（`Administrator`, `Doctor`, `Patient`）自动导航到专属的操作菜单。

### 管理员 (Administrator)

管理员负责系统的基本数据维护：

* 查看所有医生列表。
* 根据ID检查特定医生的详细信息。
* 查看所有病人列表。
* 根据ID检查特定病人的详细信息。
* 添加新医生（自动生成ID，设置姓名、密码、专业）。
* 添加新病人（自动生成ID，设置姓名、密码、年龄）。

### 医生 (Doctor)

医生可以管理他们的病人和预约：

* 查看自己的详细信息（包括专业和所管理的病人数量）。
* 查看分配给自己的病人列表（即 `Patient.BoundDoctorId` 为该医生ID的病人）。
* 查看自己的所有预约安排。
* 通过病人ID搜索并查看特定病人的详细信息（仅限自己绑定的病人）。
* 通过病人ID查看与该病人的预约记录。

### 病人 (Patient)

病人可以查看信息并预约：

* 查看自己的详细信息（包括年龄和绑定的医生ID）。
* 查看自己绑定的医生信息。
* 查看自己所有的预约记录。
* **预约流程：**
    * 如果病人当前没有绑定的医生，系统会引导他们从医生列表中选择一个进行绑定。
    * 病人可以输入未来的日期和时间以及预约状态来创建一个新的预约。
    * 新预约会自动分配给病人绑定的医生。

## 技术栈 (Technology Stack)

* **语言：** C#
* **框架：** .NET 8.0 (控制台应用)
* **数据存储：** 文本文件 (.txt)，使用 `|` 作为分隔符。

## 项目结构 (Project Structure)

* **`Entities/`**：包含核心数据模型（`BaseUser`, `Administrator`, `Doctor`, `Patient`, `Appointment`）。`BaseUser` 是一个抽象基类，定义了 `Id`, `Name`, `Password`。
* **`Services/`**：包含核心业务逻辑。
    * `AuthService.cs`：处理用户登录认证。
    * `DataContext.cs`：作为内存数据库（使用 `Dictionary` 和 `List`），管理所有实体集合，并负责调用 `FileManager` 进行加载和保存。
    * `MenuRouter.cs`：根据登录用户类型分发到对应菜单。
* **`Menus/`**：包含不同用户角色的UI和交互逻辑（`AdminMenu`, `DoctorMenu`, `PatientMenu`）。
